Overview
This project is a Legislation Management System designed to facilitate the process of bill creation, review, approval, and voting within a federal parliamentary system.

It allows:
- Legislators to create and edit bills.
- Reviewers to suggest amendments on bills under review.
- Administrators to approve, reject, or move bills to review.
- Legislators to vote on approved bills.

The system ensures a structured approval process while maintaining transparency in legislative actions.

Features
User Authentication (Admin, Reviewer, Legislator)  
Bill Creation & Editing (Legislators)  
Review Process (Reviewers suggest amendments)  
Admin Approval & Rejection (Draft → Review → Approved)  
Voting System (Legislators vote on approved bills)  
Database-Driven System (MySQL)  

Technologies Used
- PHP (Server-side scripting)
- MySQL (Database management)
- HTML & CSS (Frontend structure and design)
